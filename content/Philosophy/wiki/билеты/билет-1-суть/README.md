# wiki/билеты/билет-1-суть/

**Сжатые версии** всех ответов Билета № 1 (Раздел I «Общие проблемы философии
науки») — 25 вопросов + 11-бис = **26 файлов**, каждый на **одну страницу A4**,
для повторения перед экзаменом.

Оригинальные развёрнутые ответы — в `wiki/билеты/билет-1/`, они **не изменялись**.

## Формат каждой страницы
- **Формулировка** вопроса;
- **Суть** (2–4 фразы);
- **Главное по пунктам** — сжатый костяк ответа;
- **Определения** (3–4 термина);
- **Персоналии** с датами (одна строка);
- **Возможные доп. вопросы** (2).
