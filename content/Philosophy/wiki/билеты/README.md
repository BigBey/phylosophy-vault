# wiki/билеты/

Развёрнутые ответы на экзаменационные вопросы — **главный продукт вики**.

## Структура

Одна папка на раздел экзамена (см. [[вопросы-экзамена-сгн]]):

- `билет-1/` — Раздел I «Общие проблемы философии науки» (вопросы I-1 … I-25);
- `билет-2/` — Раздел II «Философские проблемы социально-гуманитарных наук»
  (вопросы II-1 … II-24);
- `билет-3/` — дополнительный билет (один вопрос: № 15 «Натуралистическая и
  культурцентристская исследовательские программы в экономической науке»);
- `билет-1-суть/` — **сжатые версии** всех ответов Билета № 1 (25 вопросов +
  11-бис = 26 файлов, каждый на одну страницу A4); оригиналы в `билет-1/` не
  изменяются;
- `билет-2-суть/` — **сжатые версии** всех 24 ответов Билета № 2 (каждый на одну
  страницу A4) для повторения; оригиналы в `билет-2/` не изменяются;
- `билет-3-суть/` — **сжатая версия** ответа Билета № 3 (одна страница A4);
  оригинал в `билет-3/` не изменяется.

Внутри — по файлу на каждый вопрос: `NN-<краткая-тема>.md`, где `NN` — номер
вопроса в разделе с ведущим нулём (`01`, `02`, … `25`). Напр.
`билет-1/04-стадии-эволюции-науки.md`.

## Как наполняется

Вы присылаете формулировку вопроса (query) — агент по процедуре
**Query → билет** (см. `CLAUDE.md`) собирает ответ из страниц `концепции/`,
`персоналии/`, `источники/` и пишет файл в нужную папку.

Формат ответа — см. «Билет» в `CLAUDE.md`: формулировка → план ответа →
развёрнутый ответ → определения под запись → персоналии и даты →
возможные доп. вопросы → источники → связи.
