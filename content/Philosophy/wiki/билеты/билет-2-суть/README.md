# wiki/билеты/билет-2-суть/

**Сжатые версии** всех 24 ответов Билета № 2 (Раздел II) — каждый **на одну
страницу A4**, для повторения перед экзаменом.

Оригинальные развёрнутые ответы — в `wiki/билеты/билет-2/`, они **не изменялись**.

## Формат каждой страницы
- **Формулировка** вопроса;
- **Суть** (2–4 фразы);
- **Главное по пунктам** — сжатый костяк ответа;
- **Определения** (3 термина);
- **Персоналии** с датами (одна строка);
- **Возможные доп. вопросы** (2).
