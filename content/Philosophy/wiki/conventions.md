# Договорённости по оформлению вики

Дополняет `CLAUDE.md`. Здесь — мелочи стиля, которые не хочется каждый раз
переоткрывать. Пополняется по мере работы.

## Язык и терминология

- Всё по-русски. Латинские термины — в скобках при первом употреблении:
  понимание (Verstehen), объяснение (Erklären).
- Имена иностранных авторов: русское написание + оригинал при первом
  упоминании на странице: Поппер (Karl Popper).
- Единообразие терминов: «научно-исследовательская программа» (не
  «исследовательская программа»), «постнеклассическая рациональность» (через
  дефис, без пробела).

## Оформление страниц

- Заголовок H1 = `title` из frontmatter.
- Секции — по шаблону соответствующего типа страницы из `CLAUDE.md`.
- Списки кросс-ссылок в секции «Связи» — с короткой припиской, зачем связь:
  `- [[кун-томас]] — ввёл понятие парадигмы, оппонент Поппера`.
- Даты — ISO: `2026-09-07`. Годы жизни — `(1902–1994)`, тире длинное.
- Годы работ — `«Логика научного открытия» (1934/1959)`.

## Цитаты

> Блочные цитаты — дословно. После цитаты — источник и страница:
> *(Стёпин В. С. Философия науки. Общие проблемы. М., 2006. С. 123.)*

Если формулировка пересказана своими словами — не оформлять как цитату.

## Статусы и приоритет

- Новая страница из веб-знаний без источника в `raw/` → `status: черновик`.
- `status: готово` ставим только после сверки минимум с одним `sources`.
- В `index.md` статус виден у каждой страницы — по нему планируем ревизии.

## Obsidian

- Каталог считается Obsidian-хранилищем. Граф-вью — основной способ увидеть
  сироты и хабы.
- Вложения (картинки) — в `raw/assets/`.
- Frontmatter-поля `tags`, `раздел`, `status` пригодны для плагина Dataview,
  если пользователь его подключит.

## Git

- Вся вики — git-репозиторий markdown-файлов (если пользователь инициализирует).
  Коммитить по завершении ingest или билета, отдельными осмысленными коммитами.
