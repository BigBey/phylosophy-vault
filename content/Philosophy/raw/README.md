# raw/ — сырьё (источники)

Курируемая **вами** коллекция источников для подготовки к экзамену.
LLM читает эти файлы, но **никогда не изменяет** их.

## Что сюда класть

- Учебники и главы по истории и философии науки (Стёпин, Лебедев, Микешина,
  Кохановский, Никифоров и т. п.) — в `.md`, `.pdf`, `.txt`, `.epub`.
- Программу экзамена и список билетов вашей кафедры.
- Конспекты лекций.
- Статьи и первоисточники (Поппер, Кун, Вебер, Дильтей, Гадамер…).
- Изображения и схемы — в `raw/assets/`.

## Как добавлять

1. Положите файл сюда (удобно — через Obsidian Web Clipper для веб-статей).
2. Скажите агенту: «загрузи <файл>» — запустится процедура **Ingest**
   (см. `CLAUDE.md`): агент прочитает источник, создаст конспект в
   `wiki/источники/`, разложит материал по страницам вики, обновит `index.md`
   и `log.md`.

## Именование

Свободное, но осмысленное: `степин-философия-науки-2006.pdf`,
`программа-экзамена-кафедра.md`, `список-билетов.md`, `поппер-логика-научного-открытия.pdf`.
